# Kokoro-82M

### Ultra-lightweight, high-quality text-to-speech model

Kokoro-82M is a compact TTS model with only 82 million parameters that produces natural, expressive speech rivaling systems ten times its size. Fast enough for real-time use on CPU, with support for multiple voices and styles.

<br>

---

## Features

| | |
|:---|:---|
| **82M Parameters** | Tiny footprint means fast inference even on modest hardware |
| **Natural Speech** | Prosody and expressiveness that rivals much larger commercial models |
| **Multiple Voices** | Supports a variety of English voice styles and emotional tones |
| **Open Weights** | MIT licensed — free for research and commercial applications |
